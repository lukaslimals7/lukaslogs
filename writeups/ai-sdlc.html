AI SDLC

November 2026 5 min read AI SDLC

The one-man-team kit — you are the whole company, the agent is the whole engineering org, and this is the contract between the two.

The whole thing is a loop

You are the whole company. The agent is the whole engineering org. The kit is the contract between the two: each phase writes a committed markdown artifact, and the next phase starts by reading it — never from a conversation.

That artifact is the memory. A new agent session, a different model, or a tired you at 2 a.m. resumes from the same source of truth. Constitution, intent, spike, spec, plan, build, verify, release, operate, learn — phases 1, 3 and 4 pass a deterministic gate, phase 5 is reviewed in cold context, and deploy is the one irreversible approval.

0  Constitution   once per repo        docs/constitution.md + AGENTS.md
1  Intent         what & why           docs/intent.md          OUT-xxx
2  Spike          kill the unknowns    spikes/NNN/             verdict
3  Spec           testable contract    docs/spec.md            FR-xxx AC-xxx
4  Plan           ordered packets      docs/plan.md            TASK-xxx
5  Build          agent executes      commit + report         evidence
6  Verify         cold-context review  docs/reports/REVIEW-*   PASS/FAIL
7  Release        ship + rollback      docs/releases/vX.Y.Z.md
8  Operate        signals + incidents  docs/runbook.md         INC-xxx
9  Learn          amend the rules     constitution + lessons

The law: every phase produces committed markdown; the next phase starts by reading it. No phase starts from a conversation.

The rules that actually matter

One packet, one commit, one review. If the diff isn't reviewable in ten minutes, the packet was too big. The reviewer is never the builder — fresh context, or it's theatre.

Deterministic checks beat model opinion. A failing test is a fact; "looks good" is a mood. Approval binds to a version, and autonomy scales with reversibility — deploy, delete, migrate and send always need you.

Every fix leaves a test and a line in the regressions log. And Phase 9 is not optional: a system that doesn't amend itself gets more expensive every month.

What it does not do

It does not pick your architecture — that's Phase 3, and it's yours. It does not run your agent: Hermes, Claude Code, Codex, OpenCode, Copilot, or a bare hermes chat -q all work, because the prompts are runtime-agnostic. And it does not replace tests. It sits above them: tests prove code works, gates prove work was authorized.

Get started

All you need is Python 3.8+ and a git repo. No packages, no build step — the kit is markdown and one script.

git clone https://github.com/lukaslimals7/ai-sdlc.git
cd ai-sdlc

# verify the gate works (demo workspace — should be 0 errors)
python3 tools/gate.py examples/demo-workspace

# scaffold a workspace inside your own repo
python3 tools/new_initiative.py "my-feature" --repo ~/Desktop/my-app
python3 tools/gate.py ~/Desktop/my-app/docs
